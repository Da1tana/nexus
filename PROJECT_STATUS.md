## Изменения 0.2.0

- **Охват приложений.** Каталог расширен (MAX, ТамТам, Signal, Discord, Instagram, Одноклассники, Яндекс Мессенджер, MeeTime,
  Slack, Teams, Google Chat, Outlook, Яндекс/Mail.ru/Huawei-почта и др.). Любое приложение, чьё уведомление похоже на сообщение
  (категория msg/email/social, MessagingStyle или кнопка «Ответить»), включается автоматически. Явный выбор пользователя приоритетнее.
- **Экран «Приложения»** показывает все установленные приложения с иконками и поиском: «Сохраняются», «Присылали уведомления, не
  сохраняются» (с числом пропущенных уведомлений и кнопкой «Включить все»), «Другие установленные». Приложение можно включить до
  первого уведомления; при включении NEXUS сразу перечитывает уведомления, уже висящие в шторке.
- Сводки «5 новых сообщений», «12 сообщений из 3 чатов» больше не создают фиктивные беседы.
- **Главный экран «Сообщения»**: переключатель «Диалоги / Лента», фильтры с иконками приложений, аватары из уведомлений со значком
  источника, меню по долгому нажатию (прочитано, открыть в приложении, удалить из NEXUS), пошаговая настройка при первом запуске.
- Навигация: 4 вкладки (Сообщения, Поиск, Контакты, Настройки) вместо 5 — «Входящие» и «Чаты» объединены.
- Диалог: аватар и иконка источника в заголовке, компактная панель «Ответить в …», копирование текста долгим нажатием.

### Исправление установки (03.11.2026)

- Ошибка «При анализе пакета произошла ошибка»: CI создавал новый debug-ключ при каждой сборке, поэтому версии не
  устанавливались поверх друг друга; подпись была только v2. Теперь постоянный ключ `keys/nexus-debug.jks` (только
  для debug-сборок), подпись v1+v2+v3 через `apksigner`; CI проверяет подпись, zipalign и манифест (`aapt2`),
  в описание релиза добавлены размер и SHA-256. Установленные ранее сборки нужно один раз удалить.

## Реализовано

- Разбор уведомлений: MessagingStyle (несколько сообщений, группы, свои сообщения, вложения), InboxStyle, обычный/bigText;
  игнорирование сводок групп, постоянных и системных уведомлений, собственных уведомлений; распознавание скрытого текста.
- Сохранение: источник → беседа → аккаунт/контакт → сообщения → действия → статистика, в одной транзакции.
- Удаление уведомления не удаляет историю; после перезапуска действия переинициализируются по активным уведомлениям.
- Отправка: ReplyEngine с приоритетом каналов; RemoteInput-канал; статусы SEND_PENDING/UNKNOWN/SENT/FAILED.
- Переход в исходное приложение: contentIntent активного уведомления или запуск приложения.
- Контакты: автосоздание по отправителю, ручное объединение, переименование, просмотр связанных аккаунтов.
- Настройки: приложения (вкл/выкл, уровень интеграции, очистка истории по источнику), доступ к уведомлениям,
  срок хранения (WorkManager ежедневно), удаление всех данных, описание защиты данных, тема, версия.
- Безопасность: нет INTERNET, бэкапы отключены, без содержимого в логах, TokenVault на Android Keystore.

## Не реализовано / ограничения (честно)

- Уровень C (официальные API) — ни для одного сервиса. Причины по каждому — в INTEGRATIONS.md.
- История до установки NEXUS недоступна ни для одного источника.
- База данных не зашифрована (в UI сказано прямо).
- Вложения — только тип, без содержимого.
- Работа на Huawei Nova 15 Pro / EMUI 15 не проверена на устройстве.

## Как получить APK

- GitHub → Actions → последний прогон «Build APK» → артефакт `NEXUS-debug-apk`; или
- GitHub → Releases → `debug-latest` → `NEXUS-debug.apk` (публикуется автоматически при каждом push в main).
- Локально на Windows: `gradlew.bat assembleDebug` → `releases\NEXUS-debug.apk`.
